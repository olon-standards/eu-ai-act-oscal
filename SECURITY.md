# Security policy

## Reporting a vulnerability

Please report security-sensitive problems privately through GitHub's private
vulnerability reporting feature for this repository. If that feature is unavailable,
email standards@olon.media with the subject `EU AI Act OSCAL security report`.

Do not include personal data, credentials or exploit details in a public issue. We aim
to acknowledge a report within five working days and will coordinate disclosure after a
fix or documented mitigation is available.

Legal-content corrections that do not expose a security weakness should be filed as a
normal issue or pull request.
